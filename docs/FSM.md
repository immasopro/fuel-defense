# FSM

Версия документа: 1.0

Документ описывает конечные автоматы (Finite State Machine) всех игровых сущностей.

FSM является эталоном поведения NPC.

Любой переход между состояниями, отсутствующий в данном документе, считается ошибкой.

---

# Общие правила FSM

Каждый NPC одновременно находится только в одном состоянии.

Переход между состояниями выполняется атомарно.

Во время одного обновления разрешён только один переход.

Все переходы должны быть явными.

Каждое состояние обязано иметь:

- условие входа;
- правила поведения;
- условия выхода.

==================================================
СИСТЕМА OWNER
==================================================

Автомобиль может иметь только одного владельца.

ROAD

↓

STATION

↓

ROAD

↓

SPECIAL

↓

ROAD

Допустимы только переходы через передачу владения.

--------------------------------------------------

Запрещено

ROAD + STATION одновременно

ROAD + SPECIAL одновременно

STATION + SPECIAL одновременно

---

==================================================
ИНВАРИАНТЫ
==================================================

Каждый NPC обязан иметь:

STATE

OWNER

TARGET

PHASE

Все три значения обязаны быть согласованы.

Например:

STATE = EXIT

TARGET = EXIT

OWNER = ROAD

является допустимой комбинацией.

STATE = EXIT

TARGET = STATION

является ошибкой.

---

==================================================
ОТЛАДКА
==================================================

Каждый переход FSM должен логироваться.

Формат:

[time]

Object

STATE_A

→

STATE_B

Reason

Например

[64s]

Scalper #1

THEFT

→

EXIT

Reason:

GBR_ARREST_SUCCESS

или

Fuel tank full.

Никакие переходы не должны происходить "молча".
